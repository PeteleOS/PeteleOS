LEVEL 1-2 -- USERLAND ANALYSIS
===============================

1. OVERVIEW
userland/ contains all user-space applications and system utilities.
565 build units (VERIFIED from userland/xmake.lua generator note).
Build discovery via tools/gen/gen_userland_manifest.lua (parses each program's
Makefile for PROG/SRCS/LDADD/MAN/BINOWN/BINMODE/MLINKS) -> userland/generated_manifest.lua.
Each program: target(PROG) via os_program() with add_files(SRCS), add_deps for -lxxx,
MAN install, BINOWN/BINMODE handling (including setuid flagged loudly).

2. CATEGORIES (VERIFIED FROM DIRECTORY LISTING)

  essential/bin   -- essential user commands (cat, cp, ls, ksh, chmod, etc.)
  essential/sbin  -- essential system commands (init, mount, fsck, ifconfig, route)
  system          -- system daemons/config tools; includes userland/system/config (config(8) host tool)
  development     -- awk, bc, cpp, ctags, diff, gprof, lex, m4, make, mkdep, nm, patch,
                    rpcgen, sed, unifdef, vi, vis, etc. (~20 dirs verified)
  utilities       -- large collection (tmux, top, tr, xargs, yacc, vacation, vmstat, etc.)
  network         -- network clients/daemons (ftp, ssh, bgpd, httpd in other categories INFERRED)
  security        -- acme-client, doas, ocspcheck, openssl, signify (5 dirs verified)
  libexec         -- daemons run by other programs (INFERRED: ftpd, etc.)
  multimedia      -- media tools (INFERRED)
  games           -- games (INFERRED)
  package         -- package tools (INFERRED)

3. BUILD DETAILS PER PROGRAM (VERIFIED FROM userland/xmake.lua NOTES)

  PROG: program name (fallback to dir name if absent)
  SRCS: explicit list, else recursive *.c/*.S/*.cc glob
  LDADD: "-lxxx" -> add_deps("lib<xxx>-shared") (verified: httpd, bgpd, openssl)
  MAN: man pages -> share/man/manN (section from extension)
  BINOWN/BINMODE: owner/mode, setuid flagged (verified: doas 4555, ping 4555)
  MLINKS: extra hardlinks (no real usage found in current tree)
  Generated sources: *.y (53 files, e.g. httpd/parse.y), *.l (8 files),
                     RPC .x specs (generated C committed, not regenerated by default;
                     verify-rpcgen-output.sh is opt-in check)

4. HOST-BUILD TOOLS
  Two programs built twice (target + host):
    userland/system/config (config(8) -- generates kernel ioconf.c)
    userland/utilities/mklocale (needed by resources/xmake.lua)
  Host builds use plain host toolchain (no -target flag).

5. LIBRARY DEPENDENCIES
  Every userland program links against libraries (libc always; plus libm,
  libcrypto, libssl, libutil, libevent, etc. via LDADD).
  csu/crt0.c provides _start -> main().

6. KERNEL INTERFACE
  Via libc syscall stubs (libraries/core/libc/sys/). No direct kernel struct access.
  Example: ps(1) uses kvm(3) via libkvm (extra), not direct /dev/kmem (restricted).

7. GUI DEPENDENCIES
  GUI clients (if built) use gui/lib/* (libX11 etc.) plus system libraries.
  No direct gui/->userland circularity beyond shared libs.

8. CONFIGURATION DEPENDENCIES
  Many utilities read configs/system/* and configs/etc/etc.<arch>/* at runtime.
  Example: login reads login.conf, pwd_mkdb reads master.passwd.

9. EXAMPLE MODULE: userland/security/doas
  Makefile PROG=doas, SRCS includes parse.y (yacc), BINMODE=4555 (setuid root).
  Links -lutil? (check LDADD; VERIFIED example of setuid handling).

10. REFACTORING NOTES
  Dual Makefile/xmake.lua maintenance risk (legacy Makefiles stale).
  Adding a program: create dir with Makefile (PROG/SRCS) and re-run
  xmake lua tools/gen/gen_userland_manifest.lua. Large number of programs means
  bulk changes should use generator, not hand-edit each target.
