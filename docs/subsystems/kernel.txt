SUBSYSTEM: kernel
==================

1. PURPOSE
The kernel is the monolithic, privileged core of PeteleOS. It manages hardware,
memory, processes, filesystems, networking, and provides the syscall interface to
userland. Built as a single statically-linked ELF image "bsd" plus per-arch EFI
bootloader (BOOTX64.EFI, BOOTAA64.EFI, BOOTRISCV64.EFI). VERIFIED from kernel/xmake.lua.

2. SOURCE LOCATIONS

  kernel/xmake.lua, kernel/Makefile, kernel/generated_manifest.lua
  kernel/arch/{amd64,arm64,riscv64}/  (MD)
  kernel/core/{conf,kern,sys,lib,miscfs,stand}/
  kernel/uvm/, kernel/fs/, kernel/net/, kernel/dev/, kernel/crypto/, kernel/ddb/

    Build: MD_CORE_DIRS, BUS_GLUE_DIRS, LDSCRIPT_NAMES, CMACHFLAGS in kernel/xmake.lua.
    Init: locore.S -> machdep -> autoconf -> main().

  Component: core/kern (core kernel services)
    Location: kernel/core/kern/

    kern_*.c (fork, exec, exit, proc, sig, sched, synch, malloc, pledge, unveil,

    exec_*.c, vfs_*.c, uipc_*.c, sys_*.c, tty*.c, sched_bsd.c, genassym.sh, makesyscalls.sh.
    Responsibility: process lifecycle, scheduling, syscalls, VFS, IPC, TTY.

  Component: core/sys (public kernel headers)

    Examples: param.h, proc.h, systm.h, mount.h, vnode.h, conf.h, device.h, etc.
    Consumer: every kernel .c plus libraries via os-headers.
    Build: copied to install via include/xmake.lua after_install.

  Component: uvm (virtual memory)
    Location: kernel/uvm/ (~40 files)

    uvm_amap.c, uvm_aobj.c, uvm_pager.c, uvm_swap.c, uvm_pmemrange.c, etc.
    Headers: uvm.h, uvm_extern.h, uvm_param.h, uvm_pmap.h.
    Responsibility: VM maps, fault handling, page allocation, swap, per-CPU.
    Init: uvm_init() from init_main.c; pmap bootstrap from locore.

  Component: fs (filesystems)
    Location: kernel/fs/ (ufs/{ffs,mfs,ufs,ext2fs}, nfs, msdosfs, isofs, ntfs, tmpfs)
    Files: ffs_alloc.c, ufs_lookup.c, nfs_vfsops.c, cd9660_vfsops.c, etc.

    Location: kernel/crypto/ (~30 files: aes.c, arc4.c, chachapoly.c, crypto.c, etc.)

  Component: ddb (kernel debugger)
    Location: kernel/ddb/ (~25 files: db_command.c, db_trap.c, db_elf.c, etc.)
    Responsibility: in-kernel debugging, enabled via DDB option.

4. BUILD INTEGRATION

  kernel/xmake.lua (739 lines) is the most complex file:
    Reads OS_KERNEL_MANIFEST[arch].selected_files + ioconf_c.
    KERNEL_MI_DIRS enumerated; adds MI via glob.
    Adds param.c/swapgeneric.c, per-file PER_FILE_CFLAGS, selected_files via
    PREFIXES retry, ioconf.c (on_load write), MD *.c/*.S, bus glue, add_includedirs,
    ldscript, add_deps os-headers, on_load: machine copy, vers.c, assym.h via genassym.sh.
  EFI bootloader: per-arch spec in EFI_BOOTLOADERS table -> phony on_build
  (compile -> link shared via ld.lld -> objcopy -> BOOT*.EFI).

5. INITIALIZATION ORDER
  locore.S -> pmap bootstrap -> main() (init_main.c) -> uvm_init -> autoconf
  -> scheduler -> clock -> devices -> VFS -> net -> crypto -> proc0 -> root mount -> initproc.

6. DEPENDENCIES
  Depends on: tools, include (os-headers). Consumed by: libraries (headers),
  userland (syscalls), installer (bsd image), include copy (after_install).
  Generated: ioconf.c (config(8)), assym.h (genassym.sh), vers.c, machine/ copy.
