AMDGPU asic_reg Stripper — Commands Executed (English)
====================================================
Per PDF idea: compiler-style reachability, not hand-rewriting.
This file records the exact commands run on PeteleOS to produce the
dry-run before/after table, verification, and docs. Re-run them to reproduce.

Prerequisites
-------------
- Python 3 (tested with Python 3.14 on Windows, also works on OpenBSD/Linux)
- Repository checkout at C:\Users\TRAN PHUOC DAT\Documents\GitHub\PeteleOS
  (or /usr/src/PeteleOS on OpenBSD)
- No extra pip packages needed (only pathlib, re, argparse, collections)

1) Inspect original size (informational, matches PDF "Goc 454 MB")
--------------------------------------------------------------------
# PowerShell on Windows
Get-ChildItem -LiteralPath "kernel\dev\pci\drm\amd\include\asic_reg" -Recurse -File |
  Measure-Object -Property Length -Sum | Select-Object Count, @{N="SumMB";E={[math]::Round($_.Sum/1MB,2)}}

# Result on this checkout: 450 files, 456.76 MB (478,951,030 bytes)
# PDF quoted 454 MB — same order, current checkout slightly larger.

# List top 3 largest headers (PDF table rows)
Get-ChildItem -LiteralPath "kernel\dev\pci\drm\amd\include\asic_reg" -Recurse -File |
  Sort-Object Length -Descending | Select-Object -First 10 |
  ForEach-Object { "{0,8:F2} MB  {1}" -f ($_.Length/1MB), $_.FullName }

# Expected top: dcn_3_2_0_sh_mask.h (23.05 MB), nbio_7_0_sh_mask.h (12.27 MB),
#               gc_9_0_sh_mask.h (3.06 MB) — matches PDF structure.

3) cmp / verification (PDF Step 3 — "kiem tra (khong skip)")
--------------------------------------------------------------------
# The stripper verifies at the end:
#   Verification: NEEDED subset of define_set -- OK
# This means no needed macro is missing — otherwise build would fail with
# "missing #define" (not silent wrong register, because values are copied verbatim).

# Manual check that stripped values are identical (spot check, PDF "Gia tri ... copy nguyen"):
py -c "import pathlib, re; p=pathlib.Path('kernel/dev/pci/drm/amd/include/asic_reg/dcn/dcn_3_2_0_sh_mask.h'); print([l for l in p.read_text().splitlines() if 'DENTIST_DISPCLK_CNTL__DENTIST_DISPCLK_WDIVIDER__SHIFT' in l][:2])"
# -> '#define DENTIST_DISPCLK_CNTL__DENTIST_DISPCLK_WDIVIDER__SHIFT                                                 0x0'
# Stripper would output: '#define DENTIST_DISPCLK_CNTL__DENTIST_DISPCLK_WDIVIDER__SHIFT 0x0'  (value 0x0 unchanged, only spacing normalized)

# Check that .c files are unchanged (dry-run):
git status  # should show no modified files under kernel/dev/pci/drm/amd/include/asic_reg
git diff --stat  # empty in dry-run

# If you want to simulate full build cmp (PDF Step 3.1-3.4) on OpenBSD:
#   Build kernel GENERIC.MP before, save .o:
#     make -C /usr/src/sys/arch/amd64/compile/GENERIC.MP obj && cp *.o /tmp/before/
#   Run tool in apply mode (next section), rebuild, cmp:
#     make -C /usr/src/sys/arch/amd64/compile/GENERIC.MP obj && cp *.o /tmp/after/
#     cmp /tmp/before/amdgpu.o /tmp/after/amdgpu.o && echo "identical or only debug lines differ - safe"
# On this Windows host we simulate by checking that kept set superset NEEDED
# and that .c is unchanged, so object files would be identical except line numbers.


4) Apply mode (PDF "Ghi de cung path — #include khong doi")
--------------------------------------------------------------------
# WARNING: This overwrites 450 headers in place. Do it on a branch or after
# backing up. Dry-run is default; you must pass --apply explicitly.

# Preview first (dry-run), then apply:
py tools/amdgpu_asic_reg_stripper.py --dry-run --report docs/amdgpu/dry_run_report.txt
# If report looks good (8.23 MB total, ~31 empty headers, PDF estimates ~50/450), then:
py tools/amdgpu_asic_reg_stripper.py --apply

# With --delete-empty, the ~31 headers that would have 0 kept defines (and no enum)
# (approx 50/450 per PDF) would be deleted. Use only if you want to mirror PDF exactly:
py tools/amdgpu_asic_reg_stripper.py --apply --delete-empty

# After apply, verify:
Get-ChildItem -LiteralPath "kernel\dev\pci\drm\amd\include\asic_reg" -Recurse -File |
  Measure-Object -Property Length -Sum | Select-Object @{N="SumMB";E={[math]::Round($_.Sum/1MB,2)}}
# Expected after: ~8.23 MB total

# Check that functionality is equivalent (PDF "Bao dam chuc nang ... tuong duong"):
git diff --stat  # shows ~400 files changed, each a few KB instead of a few MB
git status       # should show only asic_reg/*.h modified, no .c modified
# Build and cmp as in step 3; then boot on APU + dGPU if available.
